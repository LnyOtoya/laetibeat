# 模式页面与导航矩阵

> 状态：导航层已按 `AppMode` 动态变化；页面内容差异化仍按本文矩阵逐步实现。

## 1. 一级导航

搜索按钮独立于底部 tab，所有模式保留。最近、统计、一起听、设置通过首页 AppBar actions 进入，不占用底部 tab。

| 模式 | 底部 tab | 默认落地 |
|---|---|---|
| 本地 | 媒体库 | 媒体库 |
| Subsonic | 首页 / 媒体库 | 首页 |
| QQ 音乐 | 首页 / 媒体库 | 首页 |
| 网易云音乐 | 首页 / 媒体库 | 首页 |

实现位置：

- `AppMode.mobileDestinations`
- `AppMode.mobileInitialDestination`
- `MobileShell` 按模式配置动态生成 `AppFloatingNavBar`
- `MobileShellPage` 使用共享的目的地状态显示一级页面；切换 Tab 不 push 页面
- `MobileShell` 的 AppBar actions 提供最近、统计、一起听、设置
- 所有业务页面和播放器共用 MaterialApp root Navigator；Tab 选择与详情路由栈分离
- 有正在播放的曲目时，MiniPlayer 在全屏播放器以外的非设置页面显示，不依赖底部导航栏是否显示
- 设置路由和全屏播放器隐藏 MiniPlayer；无底部导航栏时仍为 MiniPlayer 保留系统底部安全区
- 切换模式后如果当前目的地在新目标集合中则保留，否则回到 Shell 并选择该模式默认页
- 发现页已移除，原发现页的推荐歌单与排行榜迁入首页

返回规则：

- 详情、设置、搜索、播放器等页面依进入顺序 push / pop 同一条 root 页面栈。
- Full Player 不使用独立 Navigator；从播放器返回时恢复打开它的详情页和 Shell 状态。
- 页面栈回到 Shell 根页面后，系统返回才交还给 Android。
- 皮肤可以改变导航的视觉呈现，但不能改变共享路由栈或页面返回语义。

## 2. 页面内容矩阵

### 本地

| 页面 | 内容 |
|---|---|
| 媒体库 | 本地歌曲、艺人、歌单、专辑、已下载 |
| 统计 | 本地播放历史与统计 |
| 搜索 | 本地库、LX；不显示在线源 |

### Subsonic

| 页面 | 内容 |
|---|---|
| 首页 | 私服概览、最近加入、最近播放、服务器状态 |
| 媒体库 | Subsonic 歌曲、艺人、歌单、专辑 |
| 统计 | Subsonic 播放历史；无数据时显示服务器空状态 |
| 搜索 | Subsonic + LX；不显示在线源 |

### QQ / 网易云

| 页面 | 内容 |
|---|---|
| 首页 | 网易云：首页 feed、横向推荐歌单、个性化推荐、排行榜、雷达歌单、新歌新碟等；QQ：待接对应首页接口 |
| 媒体库 | 网易云：账号信息卡 + 我的音乐（我喜欢的音乐、创建/收藏的歌单、收藏的专辑、已下载） |
| 统计 | 当前平台账号可用的听歌统计；数据不足时显示登录/空状态 |
| 搜索 | 当前平台在线源；另一平台不显示 |

## 4. 约束

- 页面内容差异不应复制数据请求逻辑，优先复用 provider / controller
- 不在本地模式显示在线登录入口
- 不在 Subsonic 模式显示 QQ / 网易云账号
- 在线平台无数据时提供登录/切换模式入口，而不是显示本地空状态
- 搜索按钮保留；具体搜索源由 `AppMode` 限制
