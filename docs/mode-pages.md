# 模式页面与导航矩阵

> 状态：导航层已按 `AppMode` 动态变化；页面内容差异化仍按本文矩阵逐步实现。

## 1. 一级导航

搜索按钮独立于底部 tab，所有模式保留。

| 模式 | 首页 | 发现 | 媒体库 | 统计 | 默认落地 |
|---|---:|---:|---:|---:|---|
| 本地 | 否 | 否 | 是 | 是 | 媒体库 |
| Subsonic | 是 | 否 | 是 | 是 | 首页 |
| QQ 音乐 | 是 | 是 | 是 | 是 | 首页 |
| 网易云音乐 | 是 | 是 | 是 | 是 | 首页 |

实现位置：

- `AppMode.mobileDestinations`
- `AppMode.mobileInitialDestination`
- `MobileShell` 动态生成 `AppFloatingNavBar`
- 切换模式后如果当前路由不在新目标集合中，自动重置到该模式默认落地页

## 2. 页面内容矩阵

### 本地

| 页面 | 内容 |
|---|---|
| 媒体库 | 本地歌曲、艺人、歌单、专辑、已下载 |
| 统计 | 本地播放历史与统计 |
| 搜索 | 本地库、LX；不显示在线源 |

### Subsonic

| 页面 | 内容 |
|---|---|
| 首页 | 私服概览、最近加入、最近播放、服务器状态 |
| 媒体库 | Subsonic 歌曲、艺人、歌单、专辑 |
| 统计 | Subsonic 播放历史；无数据时显示服务器空状态 |
| 搜索 | Subsonic + LX；不显示在线源 |

### QQ / 网易云

| 页面 | 内容 |
|---|---|
| 首页 | 网易云：`/homepage/block/page` 动态 feed（推荐歌单、猜你喜欢、雷达歌单、新歌新碟等）；QQ：待接对应首页接口 |
| 发现 | 当前平台推荐、榜单、热门、我的歌单 |
| 媒体库 | 网易云：顶部账号信息卡（头像、会员、昵称、签名、关注/粉丝/等级/听歌时长）+ 当前平台账号歌单、收藏/喜欢、最近播放 |
| 统计 | 当前平台账号可用的听歌统计；数据不足时显示登录/空状态 |
| 搜索 | 当前平台在线源；另一平台不显示 |

## 3. 当前实现状态

已完成：

- 一级导航数量与默认落地页
- 模式切换时路由集合校验
- 本地 / Subsonic 隐藏发现入口
- 在线模式隐藏本地/Subsonic 不适用的在线源提示
- 网易云首页动态 feed 与「换一批」；未知 block 安全跳过
- 网易云首页顶部六卡快捷入口：今日推荐 / 心动模式 / 歌单推荐 / 漫游 / 雷达歌单 / 相似歌曲
- 网易云首页结构：顶部大卡、私人 FM、block 卡片轮播/歌曲分栏、下拉刷新
- 不再展示「根据你喜爱的歌曲推荐」区域
- 雷达歌单标题使用完整昵称；固定展示私人 / 时光 / 宝藏 / 新歌四个（ID 固定），标题与封面按账号当日数据刷新
- 今日推荐详情页；歌单推荐、雷达歌单集合页
- 网易云首页可打开歌单 / 专辑详情，单曲可播放

待实现：

- QQ 首页对应的动态 feed
- 在线媒体库与统计内容
- 媒体库按模式切换来源
- 统计按模式切换数据源

## 4. 约束

- 页面内容差异不应复制数据请求逻辑，优先复用 provider / controller
- 不在本地模式显示在线登录入口
- 不在 Subsonic 模式显示 QQ / 网易云账号
- 在线平台无数据时提供登录/切换模式入口，而不是显示本地空状态
- 搜索按钮保留；具体搜索源由 `AppMode` 限制
